# NoSiteFinder Product Vision

Users do not buy leads.

Users buy opportunities.

NoSiteFinder should become the simplest way for a web designer to:

1. Find businesses without websites
2. Prioritize the best opportunities
3. Contact prospects
4. Track conversations
5. Close clients

Long-term positioning:

"A prospecting platform for web design agencies."

Not:

"A Google Maps scraper."

Every new feature should improve one of:

* Lead quality
* Contactability
* Conversion rate
* Workflow efficiency
