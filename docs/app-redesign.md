# Application Redesign Spec

## Goal

Make NoSiteFinder feel like a prospecting workspace rather than a search utility.

Current experience:

Search -> Results -> Leave

Future experience:

Search -> Organize -> Contact -> Track

---

## Navigation

Primary Sections:

* Search
* Lead Lists
* Pipeline
* Saved Searches
* Settings

---

## Search Results

Display:

* Business Name
* Opportunity Score
* Website Confidence
* Phone Number
* Contact Status
* Notes Indicator

Actions:

* Add To List
* Update Status
* Add Note
* Export

---

## Lead Detail View

Display:

Business Details

Website Confidence

Opportunity Score

Pipeline Status

Notes

Contact Information

History

---

## Dashboard

Show:

Leads Found

Leads Contacted

Follow Ups

Meetings Scheduled

Won

Lost

Keep simple.

---

## Design Principles

Optimize for speed.

Optimize for daily use.

Reduce clicks.

Reduce modal overload.

Avoid dashboard clutter.

Avoid unnecessary charts.

Success Metric:

User can manage prospecting without spreadsheets.
