# NOT-NOW.md

## Purpose

This file exists to prevent feature creep.

Ideas listed here may be good ideas.

They are simply not the highest leverage work right now.

A feature should only move out of this document after:

* Active users exist
* Consistent product usage exists
* Customer requests validate the need
* Revenue justifies the investment

Until then:

Do not build these features.

---

# Current Product Goal

NoSiteFinder should help a web designer:

1. Find businesses without websites
2. Organize prospects
3. Contact prospects
4. Track outreach
5. Close clients

Everything else is secondary.
