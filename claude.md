# NoSiteFinder AI Development Context

## Product

NoSiteFinder helps web designers, freelancers, agencies, and marketers find local businesses that do not have websites.

The primary customer is currently:

* Solo web designers
* Small web design agencies
* Freelancers performing outbound prospecting

The core value proposition is:

"Find businesses without websites and turn them into clients."

## Business Priorities

Priority 1:
Help users find high-quality prospects.

Priority 2:
Help users contact those prospects.

Priority 3:
Help users track outreach and close deals.

Priority 4:
Generate recurring subscription revenue.

## Product Principles

* Simplicity over complexity
* Revenue over impressive technology
* Speed over perfection
* Distribution over features
* Minimize clicks
* Optimize for daily usage

## Current Core Features

* Search businesses by category and location
* Website detection
* Opportunity score
* CSV export

## Features In Progress

1. Contact Pipeline
2. Notes
3. Website Confidence Detection
4. Email Discovery
5. Lead Lists
6. Landing Page Refresh

## Technical Guidelines

* Use existing design system where possible
* Prefer extending existing components
* Avoid introducing new dependencies unless necessary
* Mobile responsive
* Maintain TypeScript type safety
* Keep database schema simple

## Definition of Done

A feature is complete when:

* Works end-to-end
* Handles error states
* Includes loading states
* Is mobile responsive
* Has clear user feedback
* Does not break existing functionality
